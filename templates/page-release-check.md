# Website page release check

## Content
Verify claims against the target release and reconcile links with public documentation.

## UX
Check heading order, meaningful labels, visible focus, light/dark contrast, reduced motion and mobile navigation.

## Function
Check all buttons, internal anchors, external links, empty states and error paths.

## Operations
Build locally, review bundle sizes and document what changed. Deployment requires authorized release ownership and local guardrails.
